 VOGUE | Minimalist Fashion Store (Pure HTML & CSS)

A sleek, high-end fashion landing page built entirely with  HTML and CSS. This project focuses on modern design principles 

 Assignment Overview
VOGUE is a conceptual minimalist e-commerce store. The goal of this project was to replicate a professional UI using custom CSS layouts.

 Features
- Custom Grid System: Products are organized using a responsive CSS Grid.
- Responsive Navigation: A sticky header for easy access to site links.
- Interactive States: CSS-only hover effects on product cards and buttons for better user engagement.

 Tech Stack
- HTML: Semantic structure for SEO and accessibility.
- CSS: - CSS Variables: For consistent color management.
  
 Project Structure
- `index.html`: Contains the complete structure, content, and internal styling of the landing page.
