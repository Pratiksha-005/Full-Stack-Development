 VOGUE | Minimal Fashion Store

A modern, minimalist E-commerce landing page built with a focus on clean UI, smooth interactions, and dynamic product rendering.

 Live Overview
VOGUE is a high-end fashion store concept that features a responsive design, a dynamic product grid, and a functional "Add to Bag" system.

 Key Features
- Modern Minimalist UI: Built using the 'Inter' font and a grayscale color palette for a premium feel.
- Dynamic Product Loading: Products are rendered dynamically using JavaScript `map()` from a data array.
- Interactive Cart: Real-time updates to the shopping bag count with visual feedback on buttons.
- Responsive Design: Fully compatible with mobile, tablet, and desktop views using **Bootstrap 5**.
- Smooth Animations: Includes hover effects and CSS transitions for an elegant user experience.

 Tech Stack
- HTML5: Semantic markup.
- CSS3: Custom properties (variables), Flexbox, and transitions.
- JavaScript : Dynamic DOM manipulation and event handling.
- Bootstrap 5: Grid system and utility classes.
- Google Fonts: Integration of 'Inter' for modern typography.

 Project Structure
- `index.html`: Contains the layout, Bootstrap integration, and CSS styling.
- `JavaScript`: Handles product data injection and cart logic.
