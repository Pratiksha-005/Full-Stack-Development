Data Visualization Chart Application

This project is a web-based application that demonstrates how to visualize data using charts. It uses the Chart.js library to create interactive and responsive visual representations of data on a webpage.

Features

Interactive Charts: Displays data in visual formats like Bar, Line, or Pie charts.

Dynamic Scaling: Charts automatically adjust to fit different screen sizes.

Clean Interface: Simple HTML and CSS used for a focused data-viewing experience.

Integration: Demonstrates how to link external JavaScript libraries (Chart.js) with a frontend project.

Tech Stack

Frontend: HTML5, CSS3

JavaScript Library: Chart.js

Tools: VS Code, Web Browser

Project Structure
Assignment 5/
├── index.html      (Main page with Canvas element)
├── script.js      (Chart.js configuration and data)
├── style.css       (Styling for the chart container)
└── README.md       (Project Documentation)

How to Run Locally

Setup

Ensure you have a modern web browser installed (Chrome, Firefox, or Edge).

Keep all files (index.html, script.js, style.css) in the same folder.

Access the Application

Open the index.html file directly in your web browser.

Alternatively, use the Live Server extension in VS Code to view the project.

Customizing Data

Open script.js to change the labels or data values.

Refresh the browser to see the updated chart immediately.

Implementation Details

The application uses the HTML5 canvas element to render the chart.

Chart.js is linked via a CDN (Content Delivery Network) for easy access without local installation.

Data is passed as an array to the Chart object in the JavaScript file.
